# Friday Good Eats

A static website listing independent restaurants in Kitchener, Waterloo and Cambridge, Ontario where a meal costs under $40 per person, with the kind of food each one serves. Every restaurant listed has fewer than 10 locations.

Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages works as-is).

- `index.html`: page markup
- `assets/styles.css`, `assets/app.js`: styling, search and filters
- `data/restaurants.json`: the restaurant data
- `data/restaurants.js`: the same data loaded by the page (so it also works from `file://`)
